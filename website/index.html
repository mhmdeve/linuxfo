Get started

Install LinuxFo.

Install through the signed APT repository on Debian and Ubuntu, or download a package directly from GitHub Releases.

DEBIANUBUNTUAMD64ARM64

All release downloads ↗

# Add the LinuxFo signing key sudo install -d -m 0755 /etc/apt/keyrings curl -fsSL https://mhmdeve.github.io/linuxfo/linuxfo-archive-keyring.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/linuxfo.gpg sudo chmod 0644 /etc/apt/keyrings/linuxfo.gpg # Add repository and install echo "deb [arch=amd64,arm64 signed-by=/etc/apt/keyrings/linuxfo.gpg] https://mhmdeve.github.io/linuxfo stable main" | sudo tee /etc/apt/sources.list.d/linuxfo.list sudo apt update && sudo apt install linuxfo
